Family Video Encryptor

Standalone local tool. Open it directly in a browser, encrypt your video list, then paste the resulting blob into family-data.js on the site. This page never sends anything over the network - it only uses your browser's built-in Web Crypto API.

Web Crypto isn't available on this page. crypto.subtle requires a secure context. If you opened this file directly (file://) and your browser blocks it there, run a trivial local server instead and open it over http://localhost, e.g.: 
python3 -m http.server
open http://localhost:8000/tools/encryptor.html

Never commit this page's output alongside the plaintext JSON or passphrase - only the encrypted blob belongs in the repo.
